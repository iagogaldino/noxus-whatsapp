# noxus-whatsapp

Monorepo do Noxus WhatsApp — app Ionic/React com painel admin.

## Estrutura

- `apps/frontend` — aplicativo WhatsApp + admin (Ionic 8, React 19, Vite)
- `apps/backend` — backend (em breve)

## Frontend

```bash
cd apps/frontend
npm install
npm run dev
```
